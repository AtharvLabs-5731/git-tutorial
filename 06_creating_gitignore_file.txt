.gitignore — Simple Explanation
.gitignore is a Git file that tells Git which files/folders it should NOT track.
Think of it like:
    🛑 "Git, don't include these files in my repository."

Example
Suppose your project looks like this:
    MyProject/
    │
    ├── main.py
    ├── README.md
    ├── password.txt
    ├── .env
    ├── __pycache__/
    └── venv/
You don't want password.txt, .env, __pycache__, or venv to go to GitHub.

Create a file named:
    .gitignore
and write:
    password.txt
    .env
    __pycache__/
    venv/
Now Git will ignore those files/folders.

Common .gitignore patterns
    Pattern	        |   Meaning
    file.txt	    |   Ignore a specific file
    *.log	        |   Ignore all .log files
    *.pyc	        |   Ignore all Python compiled files
    folder/	        |   Ignore an entire folder
    .env	        |   Ignore environment/config secrets
    node_modules/	|   Ignore Node.js dependencies
    __pycache__/	|   Ignore Python cache

Now I ignore all the log files but I don't want to ignore important.log file 
then  in .gitignore I write : 
    !important.log -> so that it can't ignore this file

Example for a Python project
    # Python cache
    __pycache__/
    *.pyc

    # Virtual environment
    venv/
    .env/

    # Environment variables
    .env

    # IDE files
    .vscode/

    # Logs
    *.log

Important ⚠️
.gitignore does not remove a file that Git is already tracking.

For example, if you already did:
    git add .env
    git commit -m "added env"
and then add .env to .gitignore, Git will continue tracking it.
